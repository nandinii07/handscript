Installing it

macOS — double-click the .ttf, then choose Install Font in Font Book.
Windows — right-click the .ttf and choose Install.
Linux — copy it into ~/.local/share/fonts and run fc-cache -f.

Once installed it appears as {{ family_name }} in any word processor.
